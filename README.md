# 高质量数据集专项推进驾驶舱 (Data Dashboard)

本项目是专门为领导展示构建的**高质量数据集专项项目进展数据大屏**。大屏严格根据 `UI.png` 视觉原型 1:1 还原设计，数据实时读取并解析同目录下的 `专项进度表【周度更新】(5).xlsx` 数据源文件。

---

## 🌟 核心功能亮点

1. **1:1 还原 UI.png 驾驶舱原型**
   - **顶部 3 大核心 KPI 卡片**：
     - **样本进度**：89.1% 完成率、具体样本数及动态 Sparkline 趋势曲线。
     - **数据进度**：【数据生产】与【数据汇交】完成率及 PB 级别数据量，配合双色动态进度条。
     - **DMP 治理进度**：已完成（绿色）、待核对（橙色）、未填写（红色）三类状态动态统计。
   - **中部三 Tab 视图导航**：
     - 支持在 `总览`、`合同进展`、`组学进展` 之间平滑切换。
   - **中部 3 大可视化面板**：
     - **专项进度矩阵**：列出 EBP、HGP2、肿瘤专项、虚拟细胞、生物制造五大专项的样本、生产、汇交、DMP 状态和合同签署完成率。
     - **专项完成度排名**：以横向柱状图呈现各专项数据生产完成率排名。
     - **DMP 状态分布**：ECharts 环形图（Donut Chart），中心标注总计项数，右侧列出百分比图例。
   - **底部专项下钻分析明细表**：
     - 支持在组学维度、合同维度、综合总览维度下钻查看明细数据，并配备全局搜索框。

2. **动态数据读取与联动**
   - **固定路径自动读取**：页面加载时自动调取同目录下的固定数据文件 `专项进度表【周度更新】(5).xlsx`。
   - **全屏交互联动**：通过顶部“专项选择”下拉框选择特定专项（如 `EBP` 或 `HGP2`）时，全屏 KPI 卡片、矩阵、排名图表、环形图及底部下钻表格将自动重算并同步刷新。
   - **数据更新支持**：当周度更新 Excel 数据替换或上传新文件时，只需点击“刷新数据”或选择新文件即可实时同步大屏展示。

3. **零外部网络依赖 (100% 离线可用)**
   - 依赖的 JS 库（SheetJS `xlsx.full.min.js` 与 ECharts `echarts.min.js`）已全部下载存放在本地 `lib/` 目录中，无需联网即可稳定流畅运行。

## 🚀 快速启动指南

### 方式一：直接运行本地服务器（推荐）

为避免浏览器对本地 `file://` 协议 Fetch 本地 Excel 文件的 CORS 跨域限制，建议使用 Python 启动本地 Web 服务器：

1. 在项目根目录下打开命令行终端；
2. 执行以下命令启动本地 HTTP 服务：
   ```bash
   python -m http.server 8080
   ```
3. 在浏览器中打开：[http://localhost:8080](http://localhost:8080) 即可查看大屏。

### 方式二：直接双击打开 `index.html`

如果直接双击 `index.html` 打开（`file://` 协议）：
- 页面顶部提供 **“导入表格”** 按钮，选择同目录下的 `专项进度表【周度更新】(5).xlsx` 即可即时解析显示。

## 📊 数据逻辑与指标定义

- **样本完成率** = `已送样（例）` / `合ompany样本（例）` × 100%
- **数据生产进度** = `总计-实际产出（Gb）` / `总计-预计产出（Gb）` × 100%
- **数据汇交完成率** = `已汇交总数据量（Gb）` / `预计汇交总数据量（Gb）` × 100%
- **PB 单位换算** = `Gb 数值` / 1024 / 1024
- **DMP 治理状态分类**：
  - `已完成`：Excel 中“是否提交了DMP信息”为 `是`；
  - `未填写`：Excel 中“是否提交了DMP信息”为空或为 `未填写`；
  - `待核对`：Excel 中包含备注或待确认信息的条目。
